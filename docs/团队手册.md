## 1. 我们在做什么

输入一个沥青养护材料问题 → 系统在 11,143 块领域语料里混合检索 → 返回**带 `[n]` 角标、可展开原文**的答案 → 证据不足就**拒答**、信息不足就**追问**。

一句话验收标准：**答案每句话都能点到原文，点不到就不许说。**

## 4. 一个任务怎么走完

1. **认领**：Issue 下回复"认领 + 预计完成日"；有依赖未合入就先做别的。
2. **开分支**：`git switch -c feat/T09-qa-generate`（`feat|fix|test|docs|exp` + `T编号` + 短描述）。
3. **写代码 + 测试**：只改自己写域的文件；共享文件（`contracts/schemas.ts`、`app.ts`、`router.ts`、根 `package.json`、`config/`）找 A。
4. **自检**：`pnpm -r typecheck && pnpm test && git diff --stat`（≤400 行）。
5. **提 PR**：标题 `[T09] 生成与引用绑定`，正文 `Closes #9` + 贴命令和关键输出 → 找 1 人 review → **A 合入**。

拒绝的 PR：改到别人写域 / 没有测试 / 验收写成"优化体验" / 数字口径不对。

## 5. 八条硬规矩

1. **一个任务 = 一个 PR**，≤400 行 diff；超了就拆。
2. **测试只增不减**（当前基线 334 passed），`pnpm typecheck` 必须全过。
3. **共享文件只有 A 改**，需要新字段就在 Issue 里写清单，别自己动。
4. **数字唯一口径**：索引 **11,143 块**、金标准 **38 条（dev 28 + held-out 10）**、混合检索 **mean recall@5 = 0.9187**。
5. **禁止旧口径**：`241 块`、`11,087 当唯一值`、`金标准 20 条`、`38/38 = 100%`、`端到端 11–18s`。
6. **LLM 不可用就标 `llm: null`**，报告里写"未复现"，不许用 0 分冒充。
7. **涉检索/生成/拒答/语料的改动**必须附 `docs/experiments/*.json`（含生成命令）。
8. **答案必须能溯源**：`citations[].snippet` 是原文 chunk，不是摘要；`[n]` 越界必须剔除。
