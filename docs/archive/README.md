## 2. 使用规则

1. **只读**：不要在本目录内新增或修改文件；需要更新的内容写入现行文档。
2. **不引用数字**：旧材料中的规模、耗时、达标率、测试数等均已被新文档取代；引用前先查 [README](../../README.md) 与 [数据来源与清洗说明](../数据来源与清洗说明.md)。
3. **品牌与文案**：旧材料中的旧品牌仅作为历史出现，**不得复制到新文档、新 UI 或答辩材料**；前端品牌替换由 D 统一处理。
4. **不参与构建**：本目录不被 `pnpm build:index`、测试与 CI 读取，删除不影响系统运行（但会丢失过程证据）。
